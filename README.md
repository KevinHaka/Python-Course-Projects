# Python Course Projects

A collection of Python projects developed during programming courses, showcasing application development, data handling, and problem-solving.

## Projects

### [University Grading Simulator](./University%20Grading%20Simulator/)
A university grading system using file handling and SQLite.

### [31 Card Game](./31%20Card%20Game/)
A Tkinter-based card game with a computer opponent, score tracking, and Hall of Fame.

### [My-News](./My-News/)
A personalized news aggregator that fetches and displays content based on user preferences and search keywords.

## Skills Demonstrated

- Python
- Object-oriented programming
- File handling
- SQLite
- Tkinter GUI development
- Application logic
- Data persistence
