# University Grading Simulator

This project is a Python application that simulates a university grading system, utilizing file handling for names and an SQLite database for student records.

## About

This is a project for the course *"Advanced programming in Python"* offered by Mathesis (mathesis.cup.gr). The project demonstrates the application of advanced Python programming concepts, including object-oriented programming, file I/O (handling data like `actors.txt` and `actresses.txt`), and database management using SQLite (`students.sqlite.sql`). I have implemented approximately 10% of the code exclusively within the `main.py` file.

## How to Run

1. Clone the repository:
   ```sh
   git clone https://github.com/KevinHaka/Python-Course-Projects.git
   ```

2. Navigate to the project directory:
   ```sh
   cd Python-Course-Projects/"University Grading Simulator"
   ```

3. Run the application:
   ```sh
   python main.py
   ```

## Usage

- Start the application by running the main Python script.
- The script will use the provided text files and SQLite database to simulate and manage the university grading process.
