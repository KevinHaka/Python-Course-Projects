# MyNews

This project is a personalized news aggregator that fetches and displays news from in.gr RSS feeds based on user preferences. Users can select topics of interest and define search keywords to filter news articles.

## About

This is the final project for the course *"Introduction to Python"* offered by Mathesis (mathesis.cup.gr). The project demonstrates the application of Python programming concepts learned throughout the course, including file handling, web scraping, regular expressions, etc. I have implemented approximately 20% of the total code.

## How to Run

1. Clone the repository:
   ```sh
   git clone https://github.com/KevinHaka/Python-Course-Projects.git
   ```

2. Navigate to the project directory:
   ```sh
   cd Python-Course-Projects/My-News
   ```

3. Run the application:
   ```sh
   python main.py
   ```

## Usage

- Login with your username or use `admin` for administrative functions
- Select news topics and define search keywords in your profile
- View personalized news titles and full articles
