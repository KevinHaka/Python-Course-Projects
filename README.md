# Python Course Projects

A collection of Python applications developed during Python programming courses.

## Projects

### University Grading Simulator
A university grading system using file handling and SQLite.

### 31 Card Game
A Tkinter-based card game with a computer opponent, score tracking, and Hall of Fame.

### My-News
A Python project for collecting, processing, or presenting news content.

- Python
- Object-oriented programming
- File handling
- SQLite
- Tkinter GUI development
- Application logic
- Data persistence
